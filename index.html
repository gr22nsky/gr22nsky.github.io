ABOUT DERRICK2SKY

기획부터 출시까지,
하나의 흐름으로.

데릭투스카이(Derrick2Sky)는 모바일 앱을 중심으로 기획, 인터랙션, 구현을 하나의 흐름으로 연결하는 독립 소프트웨어 스튜디오입니다.

현재 KeyCap KeyRing과 가치관 기반 소셜 서비스 끼리끼리를 개발·운영하며, 아이디어 단계부터 출시 이후의 사용 경험까지 하나의 제품으로 완성하는 것을 중요하게 생각합니다.

나만의 키캡 키링을 직접 만들어보세요

KeyCap KeyRing은 레이아웃, 스위치, 키캡, 사진을 자유롭게 조합하고 결과를 바로 확인할 수 있는 커스터마이징 앱입니다. 실제 조합하는 즐거움을 모바일 화면에 자연스럽게 담았습니다.

사진 선택, 녹음과 재생, 인앱 구매와 광고 제거, 구매 복원까지 실제 출시·운영에 필요한 기능을 포함합니다.

주요 기능

다양한 커스터마이징키캡·스위치·레이아웃·사진을 조합하고 즉시 미리보기
사운드와 인터랙션키를 누르는 감각과 녹음·재생 기능

친구와 같은 질문, 다른 생각을 발견하는 즐거움

끼리끼리는 친구와 같은 질문에 답하며 서로의 가치관과 생각을 알아가는 소셜 서비스입니다. 기본 가치관 질문에서 시작해 매일 새로운 질문에 답하면서 서로의 공통점과 차이점이 쌓입니다.

친구 궁합은 최근 답변을 반영해 계속 변하며, 리포트를 통해 각자의 생각을 더 풍부하게 이해하도록 설계하고 있습니다.

주요 기능

기본 가치관기본 질문을 통해 친구 궁합의 초기 기준 설정
매일 하나의 질문서로 답한 질문을 통해 계속 발견하는 공통점과 차이점
궁합과 리포트누적된 답변으로 변화하는 궁합과 월간 분석 리포트
