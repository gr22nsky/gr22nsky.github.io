작은 아이디어를, 오래 쓰이는 제품으로

데릭투스카이(Derrick2Sky)는 모바일 앱을 중심으로 기획, 인터랙션, 구현을 하나의 흐름으로 연결하는 소프트웨어 스튜디오입니다. 보기 좋은 화면에 그치지 않고, 실제 사용 과정이 자연스럽고 운영 가능한 제품을 만드는 것을 중요하게 생각합니다.

현재 KeyCap KeyRing과 가치관 기반 소셜 서비스 끼리끼리를 직접 개발·운영하고 있습니다. 각 제품은 아이디어 단계부터 출시 이후의 사용 경험까지 하나의 브랜드로 완성하는 것을 목표로 합니다.

KeyCap KeyRing

Flutter · Android · iOS

키캡 키링을 화면에서 직접 조합하는 커스터마이징 앱

KeyCap KeyRing은 레이아웃, 스위치, 키캡, 사진 요소를 선택하면서 결과를 바로 확인할 수 있도록 만든 모바일 앱입니다. 단순한 미리보기보다 실제 커스터마이징 과정 자체가 자연스럽게 이어지도록 구성했습니다.

Flutter 기반으로 제작되며 이미지 선택, 녹음과 재생, 오디오 편집, 인앱 구매, 광고, 설정, 복원 등 실제 출시 앱에 필요한 기능까지 포함합니다.

앱 화면

실제 프로젝트 asset 사용
커스터마이징 레이아웃, 스위치, 키캡, 사진 요소를 조합하고 변경 결과를 즉시 확인합니다.
미디어 기능 사진 선택과 사운드 녹음·재생·편집 흐름을 모바일 환경에 맞게 구성했습니다.
제품 운영 인앱 구매, 광고, 설정, 구매 복원 등 출시 이후 운영을 고려한 기능을 포함합니다.

끼리끼리

가치관 기반 소셜 서비스 · 출시 준비 중

친구와 같은 질문에 답하며 서로의 생각을 알아가는 서비스

끼리끼리는 데릭투스카이(Derrick2Sky)가 개발·운영하는 가치관 기반 소셜 서비스입니다. 처음에는 기본 가치관 질문으로 시작하고, 이후 매일 공개되는 질문에 답하면서 친구와의 공통점과 차이점이 계속 쌓입니다.

궁합은 한 번의 테스트 결과로 고정되지 않고, 두 사람이 함께 답한 최신 질문을 반영하면서 계속 변하도록 설계하고 있습니다. 월간 리포트에서는 친구와 잘 맞는 주제와 다른 주제, 대표 답변, 대화에 도움이 되는 내용을 보여주는 방향으로 개발 중입니다.

출시 준비 중 정식 UI 스크린샷은 출시 준비 후 공개됩니다.

기본 가치관 가입 후 기본 질문을 통해 친구 궁합의 초기 기준을 만듭니다.
매일 질문 매일 하나의 새로운 질문에 답하고, 친구가 같은 질문에 답하면 두 사람의 궁합에 반영됩니다.
변화하는 궁합 공통 답변이 쌓일수록 최근 답변의 비중이 커져 현재의 관계를 더 잘 반영하도록 설계합니다.
월간 리포트 친구와의 공통점·차이점, 대표 답변과 커뮤니케이션에 도움이 되는 내용을 정리하는 기능을 준비하고 있습니다.
